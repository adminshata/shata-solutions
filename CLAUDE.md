# Shata Solutions — Claude Project Context

## Project
Shata Solutions is a premium SaaS/service platform for business setup, website platform, branding, domain registration, business email, automation, ecommerce, marketing, and software systems.

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS

## Existing components
- GlobalStyles from "@/components/home/GlobalStyles"
- Navbar from "@/components/home/Navbar"
- SiteFooter from "@/components/home/SiteFooter"
- useTheme from "@/lib/hooks"

## Main Goal
Help build high-converting, premium SaaS/service pages for Shata Solutions.

The output should feel like a serious commercial product, not a basic landing page.

## Coding Rules
- Keep code TypeScript-safe.
- Use Tailwind CSS only unless explicitly approved.
- Do not add external libraries unless explicitly approved.
- Do not use external images unless explicitly approved.
- Preserve existing Navbar, Footer, GlobalStyles, and useTheme patterns.
- Do not modify unrelated files unless the task explicitly requires it.
- Use local components and arrays for repeated content when helpful.
- Support light and dark mode where the page already uses theme logic.
- Avoid placeholder lorem ipsum.
- Avoid emojis in professional service pages unless explicitly requested.

## Design Freedom
You may make strong design decisions when building a full page.

Prioritize:
- Premium visual quality
- Clear conversion flow
- Clean responsive layout
- Strong information hierarchy
- Realistic UI mockups
- Modern SaaS/product storytelling
- Better spacing, typography, contrast, and polish

Do not overfit to one design style unless the user asks for it.
If the user asks for a reference style, follow that reference closely.

## Workflow
For small edits:
- Edit only the requested file/component.
- Avoid rewriting the full file.

For full page builds or full redesigns:
- You may rewrite the full page file if that produces a better result.
- Keep the required imports and app structure working.
- Summarize what changed and any risks after editing.

## Current Website Platform Direction
For app/services/website-platform/page.tsx:
- The page should feel like a premium SaaS platform, not a simple service page.
- It can draw from Duda, Shopify, Webflow, Squarespace, Hostinger, Apple, and Stripe.
- The final result should be better than a direct copy of any one reference.
- The client is not buying just a website; they get website, domain, hosting, SSL, business email, forms, CRM-ready flows, booking/orders, analytics, support, and maintenance.
